# Slash Commands — Quick Reference

Type `/` in the Claude Code chat box to see every command your version supports. Plain-English requests ("mock interview me as [interviewer name]") work too. Commands are shortcuts, not requirements.

## My project command
| Command | When to use it | Example |
|---|---|---|
| `/brief <company> interview [context]` | Before any interview | `/brief Motive interview role: ADR, interviewer: Jane Doe` |
| `/brief <company> prospect [context]` | Before a mock cold call, or to practice prospect research | `/brief <HVAC or plumbing company> prospect selling: Acme Logistics telematics` |

## Job search and interview prep
| Command | When to use it |
|---|---|
| `/sdr-resume-tailor` | Every application. Paste the job description and get a tailored, truthful, one-page resume. |
| `/grill-me` | Pressure-test my "why sales," "why this company," or any plan before an interview |
| `/humanizer` | Clean up thank-you notes, cover letters, and LinkedIn messages so they don't read as AI-written |
| `/decision-toolkit` | Compare offers, companies, or cities (e.g. [location options]) |
| `/deep-research` | Longer multi-source reports on a company or industry (deeper than `/brief`) |
| `/fact-checker` | Verify a stat before saying it in an interview |

## Building and automating tools
| Command | When to use it |
|---|---|
| `/skill-designer` | Plan a new skill (e.g. `/mock`, `/debrief`) before building it |
| `/skill-creator` | Build or edit a skill once the plan is clear |
| `/prompt-master` | Write better prompts for any AI tool |
| `/schedule` | Run something on a schedule (e.g. a weekly brief on target companies) |
| `/loop` | Repeat a task at an interval inside one session |

## Built-in session controls
| Command | When to use it |
|---|---|
| `/help` | See every available command |
| `/clear` | Start fresh when switching to an unrelated task or a different company |
| `/compact` | Shrink a long conversation while keeping the key points |
| `/resume` | Reopen a past conversation |
| `/memory` | View or edit what Claude remembers about me between sessions |
| `/model` | Switch Claude models |
| `/fast` | Toggle faster responses |
| `/config` | Change settings |
| `/mcp` | Manage connected apps (Microsoft 365, Miro, and Windsor.ai still need authorizing) |
| `/artifacts` | Find web pages Claude has published for me |

## Not slash commands, still useful
- `@browser`: tells Claude to use my Chrome. Use it for candidate portals, job postings, or anything behind my logins. Claude won't submit, confirm, or send anything without asking.

## Ignore these (they're for software projects)
`/code-review`, `/simplify`, `/security-review`, `/init`
